## Prerequisites

- Node.js (recommended version: 20+)
- pnpm (can be installed via `npm install -g pnpm`)

## How to Build and Run

1. Install dependencies using pnpm:
    ```bash
    pnpm install
    ```

2. Build the project:
    ```bash
    pnpm build
    ```

3. Preview the application:
    ```bash
    pnpm preview
    ```

4. Open the application in your browser.
